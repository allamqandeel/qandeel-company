المفتاح

  • المؤسس في المركز — المدير التنفيذي في أقرب مدار — كل حلقة أبعد = مستوى إداري أدنى
  • لون القطاع = القسم (خمسة قطاعات ثابتة)
  • حلقة مفرّغة = ينتظر (مراجعة/موافقة)
  • حلقة مكسورة = متوقف
  • متقطع = مقعد شاغر
  • حلقتان = إنابة مؤقتة
  • منارة خارجية = هدف
  • داخل مدار المدير التنفيذي = يحتاجك
  • الخطوط المضيئة = علاقات حية فقط (تفويض، مراجعة، موافقة، تصعيد). لا خطوط زخرفية.

لا جلسة مؤسس

افتح مركز القيادة من سطر الأوامر على هذا الجهاز نفسه:

qandeel-founder serve --workspace <dir>
