## How the import was done

- **Search boundary.** The search covered `E:\QANDEEL COMPANY\` only, and excluded the repository's
  own `PROJECT\` tree. Nothing outside it was searched. The boundary holds 18 ZIP archives and no
  other files.
- **Reading.** Archives were read, never modified, through .NET `ZipArchive`. Windows `tar.exe` was
  not used.
- **Copying.** Each imported file is the archive entry's bytes written unchanged, under its original
  file name. There was no re-encoding and no line-ending or whitespace change. Sources are LF,
  UTF-8 without BOM, and end with a newline, so byte identity holds on every checkout;
  `.gitattributes` keeps them LF.
- **Trailing whitespace.** Several sources use Markdown hard line breaks (two trailing spaces).
  `.gitattributes` exempts the imported source directories from Git's whitespace checks so that
  `git diff --check` passes without editing the sources.
- **Selecting the canonical copy.**
  - Stage 0–12 packages are cumulative bundles. Each stage's own documents are taken from that
    stage's package. They are byte-identical in every later bundle, which the generator checked for
    each file.
  - The five running documents (constitution, master plan, change log, checkpoint register, bundle
    README) change in every bundle. Only the Stage 12 version is current.
  - Stages 13, 14, 15 and 17 are standalone closure packages; all their entries are imported.
- **Classification** uses the documents' own status lines and closure statements, never file
  timestamps. Labels: `CANONICAL / FINAL`, `CLOSED / FROZEN`, `FINAL CLOSURE RECORD`, `SUPERSEDED`,
  `EVIDENCE ONLY`. Nothing needed `UNKNOWN — REQUIRES REVIEW`.
- **Hashes** are SHA-256. The tables below were generated from the archives' entry streams, not
  typed by hand. `npm run verify` (rule `authority-import-integrity`) recomputes every imported
  file's hash on every run. It fails on any mismatch, on a listed file that is missing, and on any
  file in this directory that is not listed.
