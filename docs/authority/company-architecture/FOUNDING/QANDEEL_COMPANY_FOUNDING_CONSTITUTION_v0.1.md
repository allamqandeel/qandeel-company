4. لا يمحو التاريخ السابق.
5. يحدّث الـ Roadmap والـ Checkpoint Register عند الحاجة.

# 2. الهدف من QANDEEL COMPANY

إنشاء نظام شركة يمكن لمحمد إدارتها من جهازه، بحيث:

# 3. المبادئ غير القابلة للتنازل حاليًا

## 3.1 Employee ≠ Model ≠ Session
الموظف ليس GPT أو Claude أو Codex، وليس Session.

الموظف =  
**Identity + Role + Authority + Knowledge + Memory + Training + History + Work State**

ويُستخدم أي Model مناسب لتشغيله.

## 3.2 Memory ≠ Canonical Truth
ذاكرة الموظف قد تكون قديمة أو ناقصة أو خاطئة.

الحقيقة الرسمية للشركة يجب أن تأتي من **Canonical Company State**.

## 3.3 No Untrained Employee in Active Duty
لا يدخل أي موظف الخدمة الفعلية قبل:
- التوجيه Orientation
- التدريب الوظيفي
- التدريب على QANDEEL
- التدريب على السوق ذي الصلة
- التدريب على السياسات والصلاحيات
- Simulation
- Assessment
- Certification

## 3.4 Clear Ownership
لكل مسؤولية أساسية Owner واضح واحد.

التعاون مسموح ومطلوب، لكن لا توجد مسؤولية أساسية «مملوكة للجميع».

## 3.5 Structured Collaboration
تواصل الموظفين يكون قابلًا للتتبع ويرتبط غالبًا بـ Goal / Project / Work Item / Decision.

## 3.6 Human Sovereignty
محمد هو Founder Authority.

الأنظمة والوكلاء لا يرفعون صلاحياتهم أو ميزانياتهم أو سلطتهم ذاتيًا دون سياسة معتمدة.

## 3.7 Innovation Inside an Envelope
الموظف يمتلك حرية الابتكار في **كيف** يحقق الهدف داخل حدوده.

لا يغيّر **لماذا** الشركة موجودة أو اتجاهها الاستراتيجي الأساسي دون سلطة مناسبة.

## 3.8 Evidence Before “Done”
لا يكفي أن يقول الموظف «انتهيت».

العمل المهم يحتاج Evidence وReview حسب مستوى المخاطر.

## 3.9 Local-first, Portable, Provider-independent
مقر الشركة الرقمي يبدأ محليًا على جهاز مملوك لقنديل، لكن الشركة لا تعتمد على جهاز واحد أو مزود AI واحد.

## 3.10 Learn From Work
كل تجربة وفشل وتصحيح يجب أن يكون قابلًا للتحول إلى تعلم مؤسسي صالح لإعادة الاستخدام.

---


## 3.11 Model / Provider Independence
QANDEEL Company must not bind employee identity, memory, authority, learning, or work state to any specific LLM provider.

Model selection is an execution choice based on measured fitness for a task. Qwen and DeepSeek are initial cost-focused candidates for evaluation, while future providers/models remain replaceable.

The system should prefer deterministic non-LLM execution whenever reasoning/generation is unnecessary.

# 7. نموذج التعلم والتطور

التعلّم ليس ميزة ثانوية. هو جزء من تعريف الموظف.

دورة التعلم:

**Work → Outcome → Review → Mistake/Insight → Lesson Candidate → Validation → Institutional/Employee Learning → Future Retrieval**

لا تُكتب كل ملاحظة تلقائيًا كحقيقة.

يجب التمييز بين:
- Observation
- Hypothesis
- Lesson
- Approved Practice
- Canonical Rule

## 7.1 بعد كل عمل مهم
يجب أن يتمكن النظام من تسجيل:
- ما الذي نجح؟

- هل يوجد Lesson يستحق الحفظ؟

## 7.2 إعادة التدريب

- يتغير دوره جوهريًا.

- يتغير السوق أو الأدوات بصورة مؤثرة.
- يظهر ضعف واضح في الأداء.
